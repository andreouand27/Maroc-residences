# Maroc Residences

One-page website for **Alba Residences by Maroc**, eight new apartments in Archangelos, Nicosia, Cyprus.

Built with React, TypeScript, Tailwind CSS and Vite.

## Getting started

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
npm run preview  # serve the production build
```

## Editing content

Contact details, location, construction date, apartment availability and the features list all live in
`src/site.ts`, so a change there updates every section of the page.
